Universal POS नया ऐप

यह Android Chrome में install होने वाला PWA है।

GitHub पर चलाने के चरण:
1. ZIP Extract करें।
2. नई GitHub repository बनाएं।
3. सभी फाइलें repository के root में upload करें।
4. Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. GitHub Pages URL Chrome में खोलें और Install App चुनें।

फीचर: Billing, Product Management, Sales History, Reports, चार Quick Prices, Add पर हर tap में +1, Add को 550ms दबाने पर Quantity Popup, sticky search, × clear, category, calculator, stock, local storage, backup/restore.

डेटा इसी डिवाइस के ब्राउज़र में रहता है। नियमित backup रखें।
